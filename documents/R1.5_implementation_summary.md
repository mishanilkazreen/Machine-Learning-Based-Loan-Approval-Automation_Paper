# R1.5 Implementation Summary: Statistical Significance, Variance Analysis, and Ablation Studies

## Overview

This document summarizes the implementation of statistical rigor enhancements to address Reviewer 1, Comment 5 (R1.5) for the MSc research paper on ML-based loan eligibility prediction. The reviewer noted "insufficient experimental depth, including lack of statistical significance testing, variance analysis, and ablation studies."

**Implementation Scope:**
- Variance analysis across cross-validation folds
- Statistical significance testing between model pairs
- Ablation studies to isolate component contributions

---

## Implementation Details

### Location in Notebook
All analysis code is in `code/juupteteryer.ipynb` in the "Statistical Rigor Analysis" section, positioned after model training and before the LIME interpretability section.

### Libraries Used
- **scipy.stats**: `ttest_rel` (paired t-test), `wilcoxon` (Wilcoxon signed-rank test)
- **sklearn.model_selection**: `StratifiedKFold`, `cross_val_score`
- **pandas**: DataFrame creation and formatting

### Modules Implemented

#### 1. Variance Analysis Module
**Function:** `compute_variance_analysis(models, X_train_sm, y_train_sm)`

**Purpose:** Reports mean ± standard deviation for all evaluation metrics across 5-fold cross-validation to demonstrate model stability.

**Key Features:**
- Uses `StratifiedKFold(n_splits=5, shuffle=True, random_state=42)`
- Evaluates 4 models: Tuned RF, Tuned XGBoost, Stacking Ensemble, Voting Ensemble
- Computes 5 metrics: Accuracy, Precision, Recall, F1, AUC
- Formats output as "mean ± std" with 2 decimal places
- Stores per-fold F1 scores for reuse in significance testing
- All four models use `best_xgb_model` in ensemble construction (Voting and Stacking are consistent)

**Output:** DataFrame with models as rows and metrics as columns

#### 2. Statistical Significance Testing Module
**Function:** `compute_significance_testing(models, X_train_sm, y_train_sm, f1_scores_dict)`

**Purpose:** Performs paired statistical tests between all model pairs to determine which performance differences are statistically significant.

**Key Features:**
- Uses paired t-test (primary) and Wilcoxon signed-rank test (supplementary)
- Generates all 6 pairwise comparisons between 4 models
- Reuses per-fold F1 scores from variance analysis (avoids redundant computation)
- Formats p-values to 4 decimal places
- Marks statistically significant differences (p < 0.05) with asterisk (*)

**Output:** Pairwise comparison matrix showing p-values for both tests

**Known Limitation:** All 6 pairwise comparisons are non-significant (p > 0.05). This is expected with only k=5 folds — paired statistical tests have insufficient power to detect differences at this sample size. This limitation is acknowledged in the interpretation cell and must be noted in the paper.

#### 3. Ablation Study Module
**Function:** `compute_ablation_study(X_train, y_train, X_train_sm, y_train_sm, X_train_sm_full, y_train_sm_full, final_model)`

**Purpose:** Evaluates the pipeline with individual components removed to quantify contributions of SMOTE, hyperparameter tuning, and feature selection.

**Key Features:**
- Defines baseline (full pipeline: SMOTE + tuned RF + feature selection)
- Implements 3 ablation conditions:
  - **No SMOTE**: Trains a fresh `RandomForestClassifier(random_state=42)` on original imbalanced `X_train, y_train` — correctly isolates the effect of removing SMOTE
  - **No Hyperparameter Tuning**: Uses default `RandomForestClassifier(random_state=42)` on `X_train_sm, y_train_sm`
  - **No Feature Selection**: Uses all original features with SMOTE reapplied (`X_train_sm_full, y_train_sm_full`)
- Delta convention: `delta = ablation_F1 - baseline_F1`
  - Negative delta: removing the component hurt performance
  - Positive delta: removing the component had no detrimental effect
  - Differences within ±0.02 are within the CV std and should not be over-interpreted

**Output:** Comparison table with baseline and three ablation conditions

## Methodology Notes

### Cross-Validation Strategy
- **Method:** 5-fold stratified cross-validation
- **Configuration:** `StratifiedKFold(n_splits=5, shuffle=True, random_state=42)`
- **Rationale:** Stratified sampling maintains class distribution in each fold
- **Reproducibility:** Fixed `random_state=42` ensures consistent fold assignments across all modules

### Statistical Tests Used

#### Primary Test: Paired t-test
- **Function:** `scipy.stats.ttest_rel`
- **Type:** Parametric test
- **Assumption:** Normally distributed differences
- **Use case:** Comparing mean F1 scores across paired CV folds
- **Significance level:** α = 0.05

#### Supplementary Test: Wilcoxon Signed-Rank Test
- **Function:** `scipy.stats.wilcoxon`
- **Type:** Non-parametric test
- **Assumption:** No distribution assumptions
- **Use case:** Provides supplementary evidence when normality is questionable
- **Significance level:** α = 0.05

### Delta Sign Convention
`delta = ablation_F1 - baseline_F1`

| Delta | Interpretation |
|-------|---------------|
| Negative (e.g. -0.05) | Removing the component decreased F1 — component contributed positively |
| Positive (e.g. +0.02) | Removing the component had no detrimental effect — within CV std, not over-interpreted |
| ~0.00 | Component had negligible impact |
