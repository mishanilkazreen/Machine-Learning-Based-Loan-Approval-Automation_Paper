## Known Issues and Limitations

### Test-Set vs CV AUC Gap
Test-set AUC (0.74–0.75) is substantially lower than CV AUC (0.88–0.91) — approximately a 15-point gap. Two contributing factors:

1. **Small test set**: Only 123 samples, making test-set estimates noisy
2. **SMOTE overfitting**: Models trained on SMOTE-balanced data overpredict the positive class on the naturally imbalanced test set

This gap must be acknowledged in the paper. The CV AUC reflects performance on balanced data; the test-set AUC reflects real-world deployment conditions.

### Class-0 Recall
Test-set class-0 recall is approximately 0.42–0.44 across all models — models fail to identify roughly half of loan rejections on unseen data. This is a direct consequence of SMOTE training on balanced data while the test set retains the original class imbalance. Discuss this trade-off in the paper (higher class-1 recall vs lower class-0 recall).

### Voting Ensemble Exclusion
The Voting Ensemble is included in the R1.5 variance analysis but excluded from R1.6 confusion matrices and ROC curves. If the paper references both sections, note this inconsistency explicitly.

Key points to discuss:

- **Class-0 recall**: Discuss the 0.42–0.44 class-0 recall as a limitation — models are better at identifying approvals than rejections on unseen data.
- **False positive vs false negative trade-off**: In a loan approval context, false negatives (rejecting good applicants) and false positives (approving bad loans) have different costs. Discuss which error type is more costly for the use case.

#### Section: Discussion
- Compare test-set and CV performance and explain the gap
- Discuss implications of low class-0 recall for real-world deployment
- Note that SMOTE improves training-time balance but does not guarantee balanced test-set performance
